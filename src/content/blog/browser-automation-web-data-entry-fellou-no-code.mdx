To get started, look for [tasks that meet these criteria](https://orpical.com/criteria-for-automation/):

1.  You do the task many times each day or week.
    
2.  The steps never change and always follow the same rules.
    
3.  The task takes a lot of your time but does not add much value.
    
4.  You need to follow strict rules or keep records for compliance.

6.  You need to finish the task quickly to meet a deadline.
