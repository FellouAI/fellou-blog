### Selenium

![Selenium](https://rms.koenig-solutions.com/Sync_data/CCE_Logo/3040-selenium(1).pngL.jpg)

Selenium is one of the oldest browser automation tools. People trust it for testing and getting data from websites. Selenium works with many coding languages and all big browsers. It has grown a lot because many people help improve it. The table below shows some [big moments in Selenium’s history](https://www.h2kinfosys.com/blog/whats-the-history-behind-selenium-automation-tool/):

| Year/Period | Milestone/Update | Description |
| --- | --- | --- |
| 2006-2008 | Selenium WebDriver | Simon Stewart at Google made this. It let Selenium talk to browsers directly. Tests became faster and more stable. |
| 2011 | Selenium 2.0 | WebDriver and Selenium RC joined together. It gave better browser control, more languages, and faster tests. |
| 2016 | Selenium 3.0 | WebDriver became the main part. Selenium RC was removed. It followed W3C rules and added mobile testing with Appium. |
| 2021 | Selenium 4.0 | Big updates came. It added Chrome DevTools support, better Selenium Grid, and improved browser connections. |

Selenium started as a small project and grew into a big tool. You can trust it for testing and getting data. It keeps up with new web changes.

## Playwright vs Selenium vs Fellou

### Architecture

There are big differences in how these tools work. Selenium uses drivers to control browsers. You write scripts that talk to these drivers. The drivers then control browsers like Chrome and Firefox. Playwright also uses scripts but connects right to browser engines. This makes it faster and gives you more control. Fellou is different. It uses an agentic browser. You tell it your goal. Its AI agents plan and finish the steps for you. Fellou’s trinity system joins the browser, workflow, and agent. This lets you automate jobs on web pages and files, not just in the browser.
