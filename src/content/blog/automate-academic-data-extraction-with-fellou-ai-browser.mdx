| Error Category | Description | Examples and Quantitative Data |
| --- | --- | --- |
| Human Error | Manual abstractors overlook or incorrectly include information (false negatives and positives) | 16% false negatives (missed medications), 10% false positives (incorrect inclusion, e.g., NSAIDs misclassified) |
| ETL/Mapping Error | Issues in data extraction due to missing data, local terminology gaps, patient ID inconsistencies, and cross-institutional mapping differences | 31% missing data causing errors, 5% local errors (missing RxNorm codes for investigational drugs), 4% patient ID issues, 1% cross-institutional mapping errors |
| Abstraction-Query Mismatch | Discrepancies between query logic and data format, complex or ambiguous instructions | 30% mismatches due to query overlooking daily orders vs continuous orders, 3% due to unclear instructions affecting query design |
