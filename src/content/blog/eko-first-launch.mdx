## Eko: The Agent Programming Language for Next-Level Automation

The Eko framework was created to abstractly represent human labor (workflows) and translate this into production-ready action sequences, freeing people from repetitive tasks. Eko (pronounced like ‘echo’) is a production-ready JavaScript framework that enables developers to create reliable agents, ranging from simple commands to complex workflows. It provides a unified interface for running agents in both computer and browser environments.

Unlike traditional automation tools that require tedious step-by-step instructions, Eko is powered by intelligence. It allows users to describe their goals in plain language, and Eko’s system autonomously creates and executes the optimal plan. From simple tasks to complex workflows, Eko adapts to the needs of its users, making automation not just efficient, but intuitive.

In the future of work, the real value won’t just lie in the tools we use, but in how we interact with intelligent systems. With Eko, you're not just using a tool — you're collaborating with an agent that understands your intentions, executes tasks on your behalf, and learns from your feedback to continuously improve.

## Core Features
Eko's strengths lie in its flexibility, autonomy, and ease of use. Here’s how it’s reshaping the automation landscape:

### Natural Language Workflow Generation

Eko introduces a new programming paradigm that combines natural language and code, allowing developers to create complex workflows in a more intuitive and efficient manner. For example:
const workflow = await eko.generate("List all PDF files modified in the last week, extract their titles, and create a summary spreadsheet.");
Eko takes care of all the complexities behind the scenes, analyzing the task, breaking it down into smaller subtasks, and selecting the right tools for each step. It’s like having a personal assistant who not only understands your needs but also knows how to take action.

Users only need to describe the task goals in natural language, and Eko will automatically plan and generate executable workflows, eliminating the need for the tedious step-by-step instructions typical in traditional programming. Unlike conventional automation frameworks, Eko doesn’t rely on explicitly defined actions but instead intelligently determines the optimal execution path based on the described goal. This "goal-driven" workflow generation approach not only enhances development efficiency but also significantly lowers the programming barrier.

### Hierarchical Planning

Eko’s two-layer execution model transforms task automation by separating planning from execution, offering a more intuitive and flexible approach. Instead of directly mapping user requests to tool calls, Eko first analyzes the desired outcome in the planning phase, breaking it down into logical subtasks and selecting the appropriate tools. This upfront planning ensures clarity and control, allowing users to inspect and adjust the plan before execution begins. Once the plan is set, Eko dynamically adapts during execution, adjusting to changing conditions without rethinking the entire task. This separation not only improves reliability but also enhances reusability and adaptability, making Eko an ideal solution for both simple and complex workflows. By combining structured planning with flexible execution, Eko offers a smarter, more efficient way to automate tasks.

### Environment-Aware Architecture

Eko’s architecture is designed to seamlessly operate across various environments, providing a flexible, environment-aware framework that adapts to different platforms and development styles. It consists of three main layers:
1. Universal Core: This central layer provides platform-independent functionality such as workflow management, tool registration, and integration with large language models (LLMs) like Claude or OpenAI. It also includes a hook system for additional customization.
2. Environment-Specific Tools: Eko tailors its tools to each environment:
  - Browser Extension Tools for tasks like tab management, web search, and DOM interaction.
  - Web Tools for web-safe capabilities like content extraction and element clicks.
  - Node.js Tools for system-level operations such as file handling and shell commands.
3. Environment Bridge: This layer manages environment detection, tool registration, resource management, and ensures secure execution across platforms. It handles security measures like API key management, user authentication, and access control, adapting to the specific needs of each environment (browser, web server, or Node.js).
Eko automatically registers tools based on the environment using a helper function, making it easy for developers to set up and work within their chosen platform. The system also provides built-in error handling to manage environment-specific issues. This multi-platform flexibility ensures that Eko can work across browsers, web environments, and local systems, enabling seamless development and integration for a wide range of use cases.
